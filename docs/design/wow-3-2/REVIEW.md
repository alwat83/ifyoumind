# Wow 3.2 visual review

The founder approved the editorial homepage in [draft PR #91](https://github.com/alwat83/ifyoumind/pull/91) at `165b5bbe6f2d9f2c3ceb424ffc289ce7bcf4080c`. Wow 3.2 starts at that commit. The design review covers the existing journey from a public example to a saved decision and the account used to manage it. Production release remains subject to founder approval.

[Brand integrity follow-up and permanent visual regression coverage](BRAND_INTEGRITY.md).

## Rendered baseline and impact assessment

Baseline screenshots were captured from the approved build with the local Firebase demo emulators. The report and account data belong to synthetic QA fixtures. Hosted Stripe pages are outside the app's visual control. Checkout evidence covers the ifYouMind entry and return screens, and browser regression tests intercept the hosted redirect.

## Shared design decisions

- The approved hero imagery, editorial composition, example interactions and report links are the reference. It keeps its original scale and whitespace.
- [Shared styles](../../../src/app/_product-design.scss) define the paper, clay and olive studio surfaces, semantic states, spacing and content widths. Instrument Serif is self-hosted and used for major headings and Discovery findings. Dense evidence, controls, report details, and print retain sans typography. Static guides compile from the same tokens using the repository's locked Sass compiler.
- Forms, buttons, square corners, wordmarks and keyboard outlines share Sass styles. Auth and legal screens also share their layouts. Dashboard accents, purple gradients and decorative shadows were reduced. Report panels, tables and comparison grids retain their hierarchy and source labels.
- Ask and Advanced use the homepage demo's olive studio colors. Narrow navigation wraps. My Data exposes its existing file picker to keyboard focus. Field labels were added for assistive technology. Existing browser-local Discovery and signed-in data behavior stay distinct.
- Pricing retains its offer order and existing $79/$39 and gated subscription contracts. The renewal interval is visually separated from the price. The existing purchase and account states use the same color roles as the app. Report and account previews do not require real billing records.

Production and demo builds, the production bundle guard, Discovery isolation, touched Angular lint, 138 fast web tests, 72 Functions unit tests and 69 integrated Hosting cases passed locally. The initial Hosting run identified duplicate font registrations due to global style inlining. The final run passed after moving the shared font-face declarations into the app shell stylesheet. The capture sweep found two pre-existing horizontal overflows, 30 px in the 320 px recovery fixture and 80 px in Ask at 390 px. The matched candidate captures had zero measured page overflow. App tests cover four widths, keyboard focus, reduced motion and accessible controls. Hosting tests also cover forced colors, text-spacing and WCAG contrast. Build logs retain style budget warnings below the hard limit. The production app's estimated initial transfer is 182.31 kB versus 182.03 kB at the baseline. The Discovery island is 66.27 kB versus 66.11 kB, excluding the shared local font files. Field performance was not measured.

The initial [authenticated CI run](https://github.com/alwat83/ifyoumind/actions/runs/43357798888) found both standalone Discovery headings ending 0.69 px below the 320 × 568 first screen on Linux Chromium. The narrow layout now reduces the space before findings. The existing assertion was retained, and all 12 local narrow standalone cases passed. The [draft checks](https://github.com/alwat83/ifyoumind/pull/92/checks) record the full workflow at the updated head. The local authenticated browser suite completed 118 passes before this Discovery-only spacing correction.

## Remaining review

- Browser coverage uses Chromium and synthetic fixtures. Physical Safari/iOS and spoken screen-reader testing are open. Some additional states are pictured at 390 and 1440 px only.
- Ask and Advanced still contain older navigation destinations inherited from the baseline. This assignment changes their appearance and keyboard access. Revising their destination map would change behavior and is outside this scope.
- Stripe owns the hosted checkout and portal UI. Redirect tests are intercepted and the screenshots cover ifYouMind's own entry and return views. No live payment, live portal, or production deployment is part of this review.
- A founder or first-time visitor still needs to judge whether the screens feel like one product. Engineering checks do not measure conversion, comprehension, or willingness to pay.
