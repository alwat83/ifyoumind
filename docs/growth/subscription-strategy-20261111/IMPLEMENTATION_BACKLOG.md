# Proposed implementation backlog

**Separate work after founder authorization.** The open PR #82 release decision and live billing gate stay on their own branch and approval path. File references are current module names. The estimates are engineering days for one person, excluding waiting for founder, payment settlement or pilot cohorts.

Reconcile attributed usage, charged invoices, fees and exceptions or label them unavailable. Prove measured production costs or a conservative launch envelope against the 60% full-usage margin floor. | Count warm/cold success, retry/failure, free and paid workload. Use the existing package scripts and pinned dependencies. Phase A/B/C/D for a first pilot is roughly 17–26 engineering days before observation and approvals. C2 adds 2–4 days if later needed. Re-estimate after inspecting the selected post-release base. Do not bundle discovery redesign, new data sources, notifications, server uploads or AI into the pricing work. Under rollback, stop new sales, keep the paid entitlements and their webhook handling intact, and reconcile verified provider state before resuming.
