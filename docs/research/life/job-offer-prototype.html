    What this prototype tests

    1. Plain-language intake. The question is typed normally. The system proposes options and asks only what changes the answer.
    2. Facts, estimates and your numbers look different. Each figure carries a chip, so nobody mistakes an estimate for a fact.
    3. Honest comparison. Small gaps read “about the same”, using the same rule as the business reports.
    4. Your priorities decide. The weights are yours. The verdict says “given your priorities”, never “the best city”.
    5. Sensitivity. If moving any one weight by 20% flips the result, the page says there is no clear winner.
    6. A next step you can do. Each step is a real-world check, not an upsell.

    Session tasks (consumer track)

    C1 10-second test · C2 compare your own two offers unaided in under 8 minutes · C3 state the result, including what is an estimate · C4 trust 1–5 · C5 would you return or share it, and with whom · C6 what would you pay for, if anything. Stated answers are never counted as demand.
